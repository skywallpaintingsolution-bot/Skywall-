# Skywall வாடிக்கையாளர்கள்

Skywall Painting Solutions-க்கான வாடிக்கையாளர் மேலாண்மை ஆப் (Tamil, installable PWA).
Customer management app for Skywall Painting Solutions: enquiries, quotes, payments, dues and WhatsApp messages.

## Features
- Dashboard: today's tasks, stats, 6-month collections chart, dues list
- Customer stages: விசாரணை → மதிப்பீடு → உறுதி → வேலை நடக்கிறது → முடிந்தது
- Per-job colour, sq ft × rate estimates, discount, payment log
- Auto-generated Tamil WhatsApp messages
- CSV export, JSON backup/restore, dark mode, works offline

## Run locally
No build step. Serve the folder with any static server:

```
python3 -m http.server 8000
```

Open http://localhost:8000 (a service worker needs http/https, not file://).

## Deploy
- **GitHub Pages:** push to `main`, then Settings → Pages → Source: *GitHub Actions*. The included workflow publishes the site.
- **Netlify:** drag the folder onto app.netlify.com/drop.

Then open the https link on a phone in Chrome and choose *Add to Home screen*.

## Data
Everything is stored in the browser's `localStorage` on that device. Use Settings → backup regularly.
Customer data is never committed to this repo.
